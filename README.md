# GART Memorial — демонстрация посадочной страницы

Статическая версия v10 для просмотра и передачи разработчику. HTML, CSS, JavaScript, изображения и шрифты находятся в `docs/`. Сборка и установка зависимостей не требуются.

## Просмотр в GitHub Pages

После загрузки этого комплекта в репозиторий откройте **Settings → Pages**:

1. Source: **Deploy from a branch**.
2. Branch: **main**, folder: **/docs**.
3. Нажмите **Save**. После завершения публикации GitHub покажет адрес сайта на этой же странице.

Для бесплатного аккаунта используйте публичный репозиторий. Не добавляйте в него пароли, токены или персональные данные заявок.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Скачать и внедрить

**Code → Download ZIP** скачивает весь комплект. Для локального просмотра распакуйте его и откройте `docs/index.html`. Для внедрения используйте содержимое `docs/`, сохраняя пути и порядок подключения CSS/JS.

В `HANDOFF.md` описаны исходные файлы и ограничения прототипа. В этом комплекте папка сайта называется `docs/`, а не `dist/`. Полный комплект для разработчика с серверной заготовкой, проверками и локальным сервером передаётся отдельно архивом `GART-landing-2026-09-17.zip`.

Формы являются демонстрационными: отправка контактов не подключена. Ссылки карточек каталога и политика обработки данных требуют интеграции с основным сайтом.
