# GART Memorial — демонстрация посадочной страницы

## [Открыть страницу в браузере →](https://iodaaa.github.io/gart-landing-preview/)

Статическая версия v10 для просмотра и передачи разработчику. HTML, CSS, JavaScript, изображения и шрифты находятся в `docs/`. Сборка и установка зависимостей не требуются.

## Скачать и внедрить

**Code → Download ZIP** скачивает весь комплект. Для локального просмотра распакуйте его и откройте `docs/index.html`. Для внедрения используйте содержимое `docs/`, сохраняя пути и порядок подключения CSS/JS.

В `HANDOFF.md` описаны исходные файлы и ограничения прототипа. В этом репозитории папка сайта называется `docs/`, а не `dist/`. Полный комплект для разработчика с серверной заготовкой, проверками и локальным сервером передаётся отдельно архивом `GART-landing-2026-09-17.zip`.

Формы демонстрационные: отправка контактов не подключена. Ссылки карточек каталога и политика обработки данных требуют интеграции с основным сайтом.

## Публикация

GitHub Pages уже настроен: ветка `main`, папка `/docs`. Изменения в этой папке публикуются автоматически после завершения сборки GitHub Pages.
